Which delta source is worth using?

Without tick data, delta is estimated from candles. This tests each estimate two ways: how often it called the direction of the next few bars, and how the strategy did with it as a filter. Pick on in-sample, trust out-of-sample.

Load your data

Files stay in your browser. Nothing is uploaded.

1 · XAUUSD candles (required) 1-minute is best: it lets you test every fractal and the intrabar delta sources. 90+ days. TradingView, MT4/MT5, Dukascopy or the helper script's CSV.
2 · Gold futures volume (optional, recommended) COMEX GC1! on the same timeframe. Spot gold feeds have tick volume or none; futures volume is real traded volume, which FRVP, VWAP and delta need to mean something.

Getting 90 days of data

  • MT5: View → Symbols → Bars, pick XAUUSD and M1, set the dates, Request, then Export Bars. MT5 times are in your broker's server clock (often UTC+2 or +3), so set the offset above.
  • TradingView: export chart data from OANDA:XAUUSD (price) and COMEX:GC1! (volume) at 1 minute. Unix timestamps are already UTC.
  • Twelve Data: run the helper script Claude sent you in chat. It saves xauusd_1min.csv and this week's Forex Factory calendar.
python3 xau_data_fetch.py --key YOUR_TWELVE_DATA_KEY --interval 1min --days 90

Twelve Data's spot gold has no volume, so pair it with a GC1! export for the volume-based filters.
